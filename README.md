# QR 계산대 (POS)

노트북 전면 카메라로 QR 코드를 찍어 장바구니에 담는 간단한 계산대 웹앱입니다.
빌드 도구 없이 HTML + CSS + 바닐라 JS로 만들었습니다.

## 달란트 카드 결제 (구글 시트 연동)

참가자마다 개인 QR(이름표 또는 폰 화면)을 주고, 판매처 카메라에 대면 구글 시트의 잔액에서 바로 차감됩니다.

```
[물품] 가격 QR 찍기 / [음식] 음식 버튼 누르기  →  손님 QR 찍기  →  잔액 차감 + "3학년 김철수 · 남은 잔액 …" 표시
```

- 장바구니가 비어 있을 때 손님 QR을 찍으면 **잔액 조회**만 합니다.
- 잔액이 모자라면 빨간 화면으로 "○○달란트 부족"이라고 알려 주고 결제하지 않습니다.
- 인터넷이 잠깐 끊겨도 같은 손님 QR을 다시 찍으면 **같은 거래번호로 재시도**해서 두 번 차감되지 않습니다.
- 종이 달란트도 계속 쓸 수 있습니다: [종이 달란트로 결제] → 시트에 "현금"으로 기록 (못 보내면 나중에 자동 재전송)
- 판매 내역에서 [결제 취소]를 누르면 카드 결제는 손님 잔액이 바로 돌아갑니다.
- 참가자는 이름표 QR을 **자기 폰 카메라로 찍으면** "내 달란트" 화면(잔액, 사용 내역, 결제용 QR)이 열립니다.

### 1단계: 구글 시트 준비 (관리자 1회)

1. 새 구글 스프레드시트 만들기 → 메뉴 **확장 프로그램 → Apps Script**
2. 기존 코드를 지우고 [`apps-script/Code.gs`](apps-script/Code.gs) 내용을 통째로 붙여넣기 → 저장
3. **배포 → 새 배포 → 유형: 웹 앱**, 실행 사용자: **나**, 액세스 권한: **모든 사용자** → 배포
   (권한 확인 창이 뜨면 본인 계정으로 허용) → 나온 `https://script.google.com/macros/s/…/exec` 주소 복사
4. 스프레드시트를 새로고침하면 메뉴에 **달란트 POS**가 생김 → **① 시트 준비하기**
5. **참가자** 탭에 학년 / 이름 / 지급 달란트 입력 (A열 코드는 비워두기) → **② 참가자 코드 만들기**
6. **③ 판매처 비밀번호 보기** → 판매 기기에 입력할 비밀번호 확인

> Apps Script 코드를 고친 뒤에는 **배포 → 배포 관리 → 수정(연필) → 버전: 새 버전 → 배포**를 해야 반영됩니다.

### 2단계: 앱에 주소 넣기

`config.js`의 `sheetUrl`을 위에서 복사한 주소로 바꾸고 GitHub에 다시 올립니다.
(참가자 폰의 "내 달란트" 화면이 이 주소를 씁니다.)

### 3단계: 판매 기기마다 (7대)

계산대 → **상품·설정** → 판매처 비밀번호, 기기 이름(예: 물품1, 음식2) 입력 → **연결 테스트** ✅
→ 계산대 위쪽에서 **[🎁 물품] / [🍢 음식]** 선택. (음식 메뉴·물품 목록은 `data.js`에 고정)

### 4단계: 이름표 인쇄

GitHub 주소에서 **상품·설정 → 🪪 참가자 이름표 QR 인쇄 → 시트에서 명단 불러오기 → 인쇄**
(A4 한 장에 10명, 학년별로 골라서 인쇄 가능. 420명이면 42장)

### 미리 연습하기 (테스트 모드)

`config.js`가 `'test'`인 상태(기본값)에서 설정의 비밀번호를 `1234`로 하면, 구글 시트 없이 그 브라우저 안에서만 동작합니다.
테스트 카드 3장(TESTAAAA 김철수 300 / TESTBBBB 이영희 50 / TESTCCCC 박민수 200)은 이름표 인쇄 화면에서 불러올 수 있습니다.

### 구글 시트에서 보는 것

| 탭 | 내용 |
| --- | --- |
| 참가자 | 코드 / 학년 / 이름 / 지급 달란트 / 사용 달란트 / **잔액(자동)** |
| 거래내역 | 거래번호(G-물품, F-음식) / 시각 / 판매처 / 기기 / 손님 / 내역 / 금액 / 카드·현금 / 정상·취소 |
| 집계 | 물품·음식 판매액과 건수, 카드·종이 결제액, 지급·잔액 총액 |

중간에 지급 달란트를 늘려 주려면 참가자 탭의 **지급 달란트** 숫자만 고치면 됩니다.

## 실행 방법

카메라는 **localhost 또는 https**에서만 동작하므로
파일을 더블클릭해서 열지 말고 로컬 서버로 열어주세요. 이 `qr-pos` 폴더에서:

```bash
npx serve .
```

또는

```bash
python -m http.server 8080
```

그다음 브라우저에서 `http://localhost:3000` (serve) 또는 `http://localhost:8080` (python)을 엽니다.
처음 열 때 카메라 권한을 **허용**해주세요.

> QR 라이브러리(html5-qrcode, qrcode.js)를 CDN에서 불러오므로 인터넷 연결이 필요합니다.

## 폰으로 접속하기

폰 브라우저는 **HTTPS 주소에서만** 카메라를 허용하므로 `http://192.168.x.x`로는 카메라가 켜지지 않습니다.
자체 서명 인증서로 HTTPS 서버를 띄웁니다. (PC와 폰이 **같은 와이파이**에 있어야 함)

1. 인증서 만들기 (최초 1회, 프로젝트 루트에서. IP는 `ipconfig`의 IPv4 주소로 바꾸세요)

   ```bash
   mkdir -p .qr-pos-cert && openssl req -x509 -newkey rsa:2048 -nodes -days 825 -keyout .qr-pos-cert/key.pem -out .qr-pos-cert/cert.pem -subj "/CN=QR POS Local" -addext "subjectAltName=IP:192.168.200.100,DNS:localhost"
   ```

   인증서는 `qr-pos` 폴더 **밖**에 둬야 개인키가 웹으로 노출되지 않습니다.

2. HTTPS 서버 켜기 (프로젝트 루트에서)

   ```bash
   npx serve qr-pos --ssl-cert .qr-pos-cert/cert.pem --ssl-key .qr-pos-cert/key.pem -l tcp://0.0.0.0:8443
   ```

   Windows 방화벽 창이 뜨면 **개인 네트워크 허용**을 눌러주세요.

3. PC에서 `https://PC의IP:8443` 을 열고 → 인증서 경고에서 **고급 → 계속 진행**
4. 오른쪽 위 **📱 폰으로 열기** → 뜨는 QR을 폰 기본 카메라로 찍기
5. 폰에서도 인증서 경고 → **고급 → 계속 진행**(iPhone은 "세부사항 보기 → 이 웹 사이트 방문") → 카메라 **허용**

폰에서는 자동으로 후면 카메라를 쓰고, 카메라 화면 오른쪽 위 버튼으로 전면/후면을 바꿀 수 있습니다.
상품·장바구니·판매 내역은 **기기마다 따로** 저장됩니다(폰의 판매 내역은 PC에 안 보임).

| 파일 | 설명 |

| `index.html` | 계산대. 물품/음식 모드, 왼쪽 카메라(+음식 버튼) / 오른쪽 장바구니, 손님 QR 결제 |

| `apps-script/Code.gs` | 구글 시트에 붙여넣을 Apps Script (GitHub에 안 올려도 됨) |
| `sales.html` | 판매 내역, 오늘/전체 판매액, 날짜별 합계, 삭제, CSV 내보내기 |

## QR 형식

- **상품 QR**: `data.js` GOODS의 id (예: `G001`). 가격은 찍는 순간 data.js에서 가져오므로 가격을 바꿔도 다시 인쇄할 필요 없음
- **금액 QR**: `AMT:금액` (예: `AMT:5000`) → 장바구니에 "5,000달란트" 항목으로 추가

같은 QR은 화면에서 1.5초 이상 사라졌다가 다시 보여야 또 인식됩니다. 미등록 QR은 빨간 테두리와 "미등록 상품" 안내가 뜹니다.

## 효과음

`sounds/scan.mp3`(인식 성공), `sounds/error.mp3`(미등록 상품) 파일을 넣으면 그 소리가 납니다.
파일이 없으면 마트 스캐너 같은 "삑" 소리를 프로그램이 직접 만들어 냅니다 (`app.js`의 `beep()`).
